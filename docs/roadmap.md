# MVP 路线图

## 已完成

- ASIN 输入校验、1688 多关键词候选采集和跨关键词去重
- Cookie/MTop 鉴权错误、JSONP 解析和离线接口测试
- 详情页证据、规格匹配、人工确认和缺失数据阻断
- 采购、物流、FBA、佣金、仓储、广告、毛利和 ROI 输出
- 汇率来源、采购价来源和输入快照追溯
- CLI、Windows GUI、脱敏样例、CI 和安全文档

## 下一阶段

1. 把佣金、仓储、广告和物流费率改为可配置方案，并保留版本化参数快照。
2. 增加 Amazon 费用导入适配器，不在核心模块内直接抓取 Amazon。
3. 增加候选差异表、人工复核队列和批量状态回写。
4. 增加真实但私有的浏览器冒烟测试，不把 Cookie 放入 CI。
5. 增加发布构建、校验和 Windows 安装包签名流程。

## 暂不进入 MVP

- 自动绕过验证码或平台风控
- 无证据地推断规格、采购价、销量或市场需求
- 自动下单、自动联系供应商或替代财务审批
- 未经授权采集或公开个人信息
