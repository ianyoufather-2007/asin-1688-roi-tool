# 数据字典

## ASIN 输入

| 字段 | 类型/单位 | 必填 | 规则 |
|---|---|---|---|
| `ASIN` | 10位字母或数字 | 是 | 自动转大写，同一文件不得重复 |
| `售价` | USD | 是 | 大于 0 |
| `CPC` | USD | 是 | 不小于 0 |
| `1688搜索关键词` | 文本列表 | 采集时是 | 多个值用 `|`、逗号或分号分隔 |
| `材质/功能/结构` | 文本 | 建议 | 用于同规格匹配 |
| `销售单元` | 文本 | 建议 | 例如 1 套、8 件套 |
| `套装数量` | 数量 | 建议 | 用于硬性匹配 |
| `配件数量` | 数量 | 视产品 | 用于硬性匹配 |
| 产品长宽高 | cm | 视产品 | 用于尺寸匹配 |
| 包装长宽高 | cm | ROI 时建议 | 用于体积物流 |
| 产品/包装重量 | kg | ROI 时至少一项 | 优先使用包装重量 |
| `FBA` | USD | ROI 时是 | 缺失则不生成完整 ROI |

## 1688 候选

| 字段 | 来源 | 规则 |
|---|---|---|
| `Offer ID`、标题、链接、供应商 | 1688 搜索 | 同一 ASIN 下按 Offer/链接去重 |
| `页面价格` | 1688 搜索 | 只作证据，不参与 ROI |
| `完整销售单元采购价` | 人工核验 | 必须大于 0，且规格与 Amazon 销售单元一致 |
| 规格字段 | 页面证据/人工补充 | 缺失时进入人工补规格状态 |
| `人工有效` | 人工 | 支持是/否覆盖自动结论 |
| `人工判断原因` | 人工 | 建议记录证据和差异 |
| `匹配分/匹配状态` | 程序 | 只用于筛选，不替代采购审批 |

## ROI 输出

| 字段 | 说明 |
|---|---|
| `采购成本` | 有效同规格候选中的最高完整销售单元采购价 |
| `物流成本` | 当前四种重量/体积公式结果取最大值 |
| `Amazon佣金` | 当前预设为售价人民币的 15% |
| `广告成本` | 当前预设 CPC、20% 广告流量占比和 10% 转化率 |
| `推测真实毛利` | 收入减采购、物流、FBA、佣金、仓储和广告 |
| `投产比` | 推测真实毛利除以采购成本与物流成本之和 |
| `状态` | 完整，或列出采购价、物流参数、FBA 等缺口 |
| `参数来源` | 内置默认参数或本次加载的 JSON 文件名；不记录本机绝对路径 |

`来源追溯` 和 `参数说明` 同时保存稳定排序的参数 JSON 快照，用于复现本次计算。配置文件允许部分覆盖，但未知字段、布尔值、非有限值和越界值会被拒绝。

所有金额和比率都应结合实际报价、类目费率、退货、税费和仓储周期复核。
